# Contributing to NextClaims

Thanks for helping improve NextClaims.

## Reporting issues

Open a GitHub issue with steps to reproduce, the expected result, the actual result, and your Minecraft/server version if relevant.

## Proposing changes

1. Create a branch for your change.
2. Keep each change focused and document any behavior changes.
3. Build and test changes where possible using the instructions in README.md.
4. Open a pull request explaining what changed and how you tested it.

Please avoid including credentials or other secrets in issues and pull requests.
